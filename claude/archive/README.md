# Archived Documentation

This directory contains historical documentation from completed sprints. These documents are preserved for reference but are no longer actively maintained.

## Contents

### `/sprints`
Sprint-specific planning, coordination, and tracking documents from completed sprints (1-20).

**Archived files include:**
- Sprint 1-10 planning and tracking documents
- Sprint 11-12 planning and test strategy documents
- Sprint 15 implementation plan
- Phase 2 planning summaries (Sprints 10-15 now complete)

**Note**: For current sprint information, see:
- `claude/NEXT_STEPS.md` - Current status and next actions
- `claude/sprint_plan.md` - Overall roadmap and sprint overview
- `claude/phase_3_sprint_plan.md` - Phase 3 sprints (16-23)
- `claude/sprint_23_test_coverage_plan.md` - Current sprint details

## Why Archive?

Keeping old sprint documents in the main `claude/` directory:
1. Creates clutter and confusion about what's current
2. Increases context size for Claude agents unnecessarily
3. Makes it harder to find relevant documentation

Archived documents remain available for historical reference when needed.
