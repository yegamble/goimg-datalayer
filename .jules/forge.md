## 2026-02-12 - Critical CI Failure Swallowing in E2E Tests
**Issue:** The `e2e-tests` job in `.github/workflows/ci.yml` was passing even when tests failed.
**Root Cause:** The `Run Newman E2E tests` step had `continue-on-error: true` set, causing the step to always succeed. While this allowed subsequent report generation steps to run, the job itself was marked as successful, and the `ci-success` job (which depends on `e2e-tests` result) also passed. Additionally, the API server health check loop would exit successfully even if it timed out, proceeding to run tests against a dead server.
**Fix:** Removed `continue-on-error: true` from the Newman step (subsequent steps use `if: always()` so reports are still generated). Updated the API server startup loop to explicitly `exit 1` if the server fails to become ready within the timeout period. Also removed redundant fixture creation that was overwriting version-controlled test data.
